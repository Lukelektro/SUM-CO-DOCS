# Roadmap

El roadmap resume la dirección de trabajo sin fechas comprometidas.

## Base construida

- aplicación de escritorio y estructura de navegación;
- interfaces para las principales áreas operativas;
- backend modular y configuración por entorno;
- modelo relacional PostgreSQL y pruebas locales;
- validación local de autenticación, autorización y contenedor.

## En desarrollo

- integrar los módulos de negocio con la API y la persistencia;
- validar la composición de servicios en STAGING;
- completar recorridos de extremo a extremo con identidad y datos controlados;
- mejorar cobertura de calidad para los flujos operativos prioritarios.

## Siguiente etapa

- ejecutar y revisar operaciones reales controladas en STAGING;
- completar integración de documentos y otros servicios externos;
- evaluar preparación para producción después de cerrar validación, QA y operación.

La secuencia puede cambiar según resultados de integración y pruebas. No se publican fechas ni compromisos de despliegue hasta que estén confirmados.
