# Anexos y procedencia

Este directorio contiene una figura conceptual propia del compendio y una tabla de procedencia. No se copiaron archivos DUOC originales, documentos completos de terceros, SQL, capturas con datos reales ni logs operativos.

## Incluido

- [Modelo de datos conceptual](modelo-conceptual.svg): síntesis visual de dominios que aparecen en el modelo documentado. Es una explicación académica, no un ERD exhaustivo ni una afirmación de que todos los dominios estén implementados.
- [Procedencia y alcance](procedencia-y-alcance.md): fuentes consultadas, selección y exclusiones.

## Criterio de divulgación

El compendio público omite nombres de integrantes, asignaciones, datos personales, datos de clientes, identificadores de recursos, configuración y hallazgos internos de seguridad. Las guías académicas DUOC se citan como referencia de estructura, sin adjuntar ni reproducir su contenido completo.
